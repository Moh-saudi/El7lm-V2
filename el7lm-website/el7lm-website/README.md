# موقع El7lm (نسخة ثابتة)

موقع بدون أي مكتبات أو خطوات بناء. الصفحات: الرئيسية، المكاتب (`#offices`)، وصفحات الخدمات (`#p/clubs` وغيرها).

## التشغيل
افتح المجلد في Antigravity كـ Workspace، أو من الطرفية:
```
python3 -m http.server 8000
```
ثم افتح `http://localhost:8000`.

## أين أعدّل؟
| ما تريد تغييره | الملف |
|---|---|
| أي نص أو ترجمة (5 لغات) | `js/i18n.js` (كل مفتاح: `[en, ar, fr, es, pt]`) |
| الألوان والمسافات | `css/style.css` (متغيرات `:root`) |
| روابط التواصل والواتساب والمتاجر | `index.html` (الفوتر وقسم Nisr) و`js/main.js` (مصفوفة `SO` للحسابات) |
| الفيديو والصور والشعار | مجلد `assets/` (استبدل الملف بنفس الاسم) |
| الدول والعناوين | `js/main.js` (`C`) و`js/i18n.js` (`c_*`, `ci_*`, `ad_*`) |

## دمجه في مشروعكم الكبير
- **كموقع ثابت:** انسخ المجلد كما هو إلى مجلد الملفات العامة (`public/` أو أي استضافة ثابتة)، أو انشره على نطاق فرعي.
- **داخل مشروع React / Next.js / غيره:** اطلب من وكيل Antigravity تحويل الأقسام إلى مكونات، وتحويل `i18n.js` إلى ملفات ترجمة لكل لغة (انظر الطلب الجاهز في الأسفل). كود الكرة الأرضية يعمل على `<canvas>` ويحتاج مكوناً يعمل في المتصفح فقط.
