# نطاق النسخة الأولى

## اللاعب

1. التعريف واختيار نوع الحساب.
2. إنشاء حساب/دخول برقم الهاتف وOTP.
3. الرئيسية.
4. البحث عن اللاعبين وكروت اللاعبين.
5. سينما اللاعبين العمودية.
6. الفرص والتقديم.
7. الملف الرياضي والسيرة الذاتية.
8. قائمة تفتح أقسام الويب غير المنقولة بعد.

## بقية الحسابات

- الرئيسية.
- إدارة اللاعبين المرتبطين بالحساب.
- إنشاء كود ورابط دعوة.
- قائمة أقسام الويب.

## خارج النسخة الأولى

- نقل الإدارة المتقدمة والتقارير والبطولات والمتجر بالكامل إلى Flutter.
- المدفوعات؛ جميع الحسابات مجانية حاليًا.
- الإشعارات الأصلية ورفع الفيديو داخل التطبيق.
- تحرير ملفات الجهات بالكامل.
