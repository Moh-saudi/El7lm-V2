## 🎯 الهدف الأساسي للجلسة:
اختبار دورة المحادثة الصوتية الكاملة للمدرب الذكي **«نسر» (Nisr Voice-to-Voice AI)** على المحاكي / الهاتف المتصل، والتأكد من سماع صوت المدرب بوضوح وتجاوبه مع صوت اللاعب.

---

## 📋 خطوات الاختبار على المحاكي:
1. **تشغيل التطبيق على المحاكي / الجهاز:**
   ```bash
   flutter run -d 127.0.0.1:7555
   ```
2. **الانتقال لشاشة نسر الرئيسية (`NisrHomeScreen`):**
   - تسجيل الدخول بحساب لاعب.
   - فتح التبويب الأول (الرئيسية 🏠).
3. **اختبار الإرسال الصوتي (Voice Input):**
   - الضغط على زر الميكروفون 🎙️ في شريط الإدخال السفلي.
   - التحقق من ظهور شريط التسجيل الأحمر مع عداد الثواني (`أنا أسمعك الآن... 00:03`).
   - نطق سؤال كروي (مثال: *"كابتن نسر، كيف أطور سرعتي في الانطلاق بالكرة؟"*).
   - الضغط على زر الإرسال.
4. **التحقق من معالجة الذكاء الاصطناعي:**
   - تحول الحالة إلى **«جاري التحليل والكتابة... ⏳»**.
   - وصول التسجيل لـ `/api/nisr/chat` بصيغة `audio/l16` وفهمه عبر Gemini.
5. **اختبار الرد الصوتي (Voice Output / TTS):**
   - استلام إجابة نسر الفنية مكتوبة مع مقطع صوتي مسموع `audio/wav`.
   - **بدء التحدث التلقائي:** سماع صوت نسر فوراً عبر سماعات المحاكي/الهاتف.
   - ظهور زر **«المدرب يتحدث الآن... ⏸️»** مع إمكانية الإيقاف المؤقت أو إعادة التشغيل.
   - وجود خيار الاستماع لتسجيل اللاعب الصوتي المرسل.
