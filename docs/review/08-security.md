## 3. فحص الأسرار والمتغيرات الحساسة (Secrets & Credentials)

- **ملفات البيئة والمفاتيح السرية:**
  - مفتاح الخدمة `SUPABASE_SERVICE_ROLE_KEY` معزول على الخادم ولا يحمل البادئة `NEXT_PUBLIC_` [مؤكد بالكود].
  - لا توجد مفاتيح صريحة (Hardcoded Secrets) داخل الملفات البرمجية المفحوصة؛ يتم استدعاؤها عبر `process.env` في Next.js ومن خلال `AppConfig` في Flutter.
- **التوصية:** إجراء فحص دوري لسجل الـ Commits في Git للتأكد من عدم تسريب أي أسرار تاريخياً قبل اعتماد النشر النهائي.
